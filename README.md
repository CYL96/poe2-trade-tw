# POE2 Trade zh

用于《流放之路 2》（Path of Exile 2）国际服交易网站的中文化浏览器扩展，让交易页面支持中文装备、词缀搜索，并翻译页面界面与搜索结果。

## 项目来源

**本项目基于 [POE2DB](https://poe2db.tw/) 的汉化插件修改而来，并非从零开发。** 感谢 POE2DB 及原插件作者提供的汉化基础与相关工作。本仓库在原插件基础上进行修改与适配，包含交易搜索数据加载与缓存相关调整。

## 支持范围

- 目标网站：`https://www.pathofexile.com/trade2/*`。
- 当前提供繁体中文汉化（`zh_tw`），可切换回英文；弹窗暂未开放简体中文选项。
- 汉化内容包括装备名称、词缀、筛选条件、部分界面文字与搜索结果；实际覆盖范围取决于翻译数据。
- 部分词缀与交易数据会保留英文对照；新赛季内容可能需要等待中文数据更新。

## 部署教程

本项目是 Manifest V3 浏览器扩展，**无需部署服务器，也无需安装 Node.js、执行 npm install 或编译打包**。下载源码后，通过浏览器的开发者模式加载即可。

### 1. 准备源码

1. 在本仓库页面点击 **Code → Download ZIP**，下载源码压缩包。
2. 将压缩包完整解压到一个固定目录，例如 `D:\browser-extensions\poe2-trade-tw`。
3. 确认待加载的目录下直接包含 `manifest.json`、`options.html`、`js/`、`json/`、`lib/` 和 `images/`。

> 不要直接选择 ZIP 文件，也不要选择解压后多套的一层父目录。扩展加载后仍会使用该目录中的文件，请勿删除或随意移动目录。

### 2. 加载扩展

建议使用最新版桌面 Chrome 或 Microsoft Edge。

#### Google Chrome

1. 在地址栏打开 `chrome://extensions/`。
2. 开启右上角的 **开发者模式**。
3. 点击 **加载已解压的扩展程序**。
4. 选择上一步中直接包含 `manifest.json` 的目录。
5. 确认扩展列表中出现 **POE2 Trade zh**，且处于启用状态。

#### Microsoft Edge

1. 在地址栏打开 `edge://extensions/`。
2. 开启 **开发人员模式**。
3. 点击 **加载解压缩的扩展**，选择直接包含 `manifest.json` 的目录。
4. 确认 **POE2 Trade zh** 已启用。

> 不同浏览器版本的按钮名称可能略有差异。若设备由组织管理，策略可能禁止加载未打包扩展，需要联系管理员。

### 3. 启用汉化

1. 打开 [POE2 国际服交易网站](https://www.pathofexile.com/trade2/)，按网站要求登录账号。
2. 点击浏览器工具栏的扩展按钮，打开 **POE2 Trade zh**。可以先将其固定到工具栏，方便后续操作。
3. 点击 **繁體中文化(zh_tw)**。
4. 等待加载进度结束，确认“目前語系”显示 `zh_tw`。
5. **手动刷新交易页面**，使汉化生效；首次同步数据时，页面可能再自动刷新一次。
6. 在装备名称或词缀筛选框中输入繁体中文，检查候选项是否显示中文或中英对照。

首次应用汉化需要联网获取国际服和台服交易数据，请确保能够访问 `www.pathofexile.com` 与 `pathofexile.tw`。仅加载扩展并不会自动启用中文，仍需在弹窗中选择语言。

### 4. 更新插件与数据

**更新插件源码：**

1. 下载最新源码，完整解压并替换原扩展目录中的对应文件。
2. 打开浏览器扩展管理页面，点击 **POE2 Trade zh** 的重新加载按钮。
3. 打开插件弹窗，点击 **清除快取**。
4. 等待初始化完成后，重新点击 **繁體中文化(zh_tw)**，等待加载结束，再刷新交易页面。

通过“加载已解压的扩展程序”安装的版本需要手动更新，不会自动同步本仓库的修改。

仓库每次提交都会更新 `manifest.json` 版本，并创建对应的 `v<version>` 注解 tag；tag 注解使用中文总结本次版本的实际更新内容，提交与 tag 一起推送。具体提交约束见 [AGENTS.md](./AGENTS.md)。

**仅刷新交易数据：** 游戏更新或新赛季开始后，可直接在弹窗中执行“清除快取 → 重新应用繁体中文 → 刷新交易页面”。未收录的装备名称可能还需要更新本仓库中的翻译文件；清除缓存不能补齐尚不存在的翻译。

### 5. 恢复英文或卸载

- **恢复英文：** 在插件弹窗中点击 **還原回英文(US)**，等待完成后刷新交易页面。
- **卸载：** 建议先恢复英文并刷新交易页面，再到扩展管理页面移除插件，避免页面继续使用已经写入的中文缓存。

## 常见问题

### 加载扩展时提示找不到清单文件

确认已完整解压，且选中的目录下直接包含 `manifest.json`，而不是它的父目录或 ZIP 文件。

### 页面仍然是英文，或只有部分内容汉化

1. 确认访问的是国际服 `/trade2/` 页面，而不是 POE1 交易页面或其他域名。
2. 确认扩展已启用，并允许在目标网站上运行。
3. 确认弹窗中的语言为 `zh_tw`，且数据加载已经完成，再刷新页面。
4. 尝试“清除快取 → 重新应用繁体中文 → 刷新交易页面”。
5. 如果装备或界面已汉化，但筛选条件仍为英文，先确认已重新加载最新源码，再执行上述缓存刷新步骤。
6. 如安装了其他交易汉化扩展，可暂时禁用它们，排除同时修改页面导致的冲突。

当前使用繁体中文数据，简体中文关键词不一定能匹配。尚未收录的内容也可能继续显示英文。

词缀翻译支持数值中包含范围、空白或换行的详细描述，并保留英文对照。无法匹配的词缀会保留原文，不会重复插入英文或猜测数值。如果同一词缀在不同装备上出现“一个中文、一个双份英文”，请先重新加载新版扩展并刷新交易页面。

搜索结果标题与天赋说明直接读取当前扩展自带的翻译文件，不再依赖 `chrome.storage.local.translation` 中的旧名称或天赋表；更新源码并重新加载扩展后，刷新交易页面即可应用这些翻译，无需为此清除快取。词缀、搜索候选及筛选条件的交易数据仍通过缓存加载，刷新这些数据时按上文执行清除快取流程。

结果页已按用户实际页面的新版 DOM 适配：标题使用 `.item-popup__header-line`，天赋说明使用带 `--colour-augmented` 样式的名称元素；不再依赖旧版 `.itemHeader`、`.notableProperty` 等选择器。浏览器诊断和验收命令由维护者提供、用户自行执行；本地 DOM 回归不等于登录交易页的实际验收，具体约束见 [AGENTS.md](./AGENTS.md)。

天赋表已按 [POE2DB 天赋树数据](https://poe2db.tw/us/passive-skill-tree/) `4.5` 快照全量同步，覆盖 4,928 个有本地化名称的节点、2,009 个英文名称、2,278 种名称与效果组合，其中包含 984 个主树核心天赋节点；包含小天赋、关键天赋、昇华，以及有名称但无效果的起始节点或专精。繁中与简中数据均收录，弹窗仍只开放繁中。224 个无效果且没有中文名称的开发占位节点不收录，旧 POE1 天赋表已移除。

天赋说明按英文名称及实际英文效果匹配，同名不同效果分别翻译，中英文换行数量不必相同，并保留英文对照。未知名称或效果数值变化时保留原文，不拿旧版效果替换。上游未本地化的内部字段采用标明「內部資料」的直译并保留原文，不将字段值猜成游戏效果。

**维护天赋数据**（安装 Node.js 后执行；用户安装扩展不需要执行）：`node scripts/update-passives.mjs` 重新获取中英数据、按天赋 ID 对齐并生成本地快照；`node scripts/update-passives.mjs --check` 校验本地快照与上游数据一致。同步脚本会拒绝缺失翻译或同一英文效果对应互相冲突的中文效果；上游快照版本改变时，先更新脚本中的数据路径，再执行同步与浏览器验证。

### 点击汉化后一直处于加载状态

数据初始化依赖国际服和台服交易接口。请检查网络连接，以及相关网站是否出现维护、访问限制或验证提示。恢复访问后，清除缓存并重新应用汉化；持续失败时，可在扩展管理页面打开该扩展的 Service Worker 检查视图查看错误信息。

### 新赛季的装备或词缀搜不到

先清除缓存并重新应用汉化，以获取最新交易数据。中文词缀还取决于台服数据更新，装备名称还取决于本地翻译文件；更新前可尝试使用英文搜索，或暂时恢复英文。
